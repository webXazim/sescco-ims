# Storekeeper guide

## Add stock

Select the project and enter material, supplier and phone information. The
system matches stock by project, normalized material, normalized supplier and
normalized supplier phone. Review the existing-record preview before saving.
Every addition remains in the stock detail history.

## Use stock

Select an existing stock record and enter the quantity, purpose and recipient
or work section. The form shows the available balance and blocks negative stock.

## Search and export

Use Inventory for current balances and Activity for additions and usage. Apply
project, material, supplier, phone, quantity, price, user and date filters.
Date presets include today, week, month, quarter, year and custom date-to-date.
Exports include every matching record, not only the current page.

## Corrections

Do not create an opposite fake transaction to hide a mistake. Contact the
administrator, who can create a linked reversal while preserving history.
